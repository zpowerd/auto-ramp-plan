Pipeline and yield

Review layers

Evals

Mark the layers that are evals rather than human review. Evals take no contributor time and happen instantly.

Domains and targets

Split by domain when contributors only work tasks in their own domain. Each domain then has its own contributors, tasks and target. The pipeline, yields and attempt times are the same for every domain.

Task target is how many tasks need to reach L12. Tasks waiting are already sitting in a review layer when the plan starts; L−1 has an unlimited supply of new tasks.

Assumptions

Hours per day is the average an active contributor works. Hours per attempt is how long one attempt takes in each layer.

CB ramp

New CBs join the project at L−1, a set number a day in each period (below 0, CBs leave). Each review layer then converts CBs up from the layer below it: a set number a day, or as many as it takes to keep a % of the CBs L0 had the day before, rounded to whole CBs and at least 1. At L0 itself, 100% holds it steady, refilling what moves up, and more than 100% grows it. A layer can only convert as many as the layer below has, and nobody moves up more than one layer a day. CBs are counted by the highest layer they can work, and evals get none. Each domain gets this ramp.
